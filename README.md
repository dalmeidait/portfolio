# Portfólio profissional — Daniel Barros Almeida

Site corporativo em português, com apresentação pessoal, foto profissional, competências em infraestrutura e Microsoft Cloud, certificações e três estudos de caso.

## Visual e tecnologia
- Tema azul-marinho, comunicação formal e layout responsivo.
- Sem frameworks: HTML semântico, CSS e JavaScript.
- Foto autorizada pelo titular, otimizada para WebP em `assets/foto-daniel.webp`. O arquivo é destinado exclusivamente à apresentação neste portfólio.
- Otimização para dispositivos móveis e navegação acessível.
- Projetos apresentados com diagramas **ilustrativos**, distintos das evidências técnicas.

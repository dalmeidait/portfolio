# Portfólio de Daniel Barros Almeida

Site profissional em português com foco em infraestrutura de TI, Microsoft 365, cloud e segurança.

## Sobre

O site é estático, responsivo e não depende de frameworks ou serviços externos. Contém apresentação profissional e estudos de caso dos projetos AvanceOS — Microsoft 365, Oficina Avance — On-Premises e Oficina Avance — Migração M365.

## Publicação

Repositório de origem: `dalmeidait/portfolio`.

- Publicação como *project site*: https://dalmeidait.github.io/portfolio/ (dependente das configurações de Pages).
- Para publicar em https://dalmeidait.github.io/, o repositório deve se chamar `dalmeidait.github.io` e ter o GitHub Pages configurado.

O arquivo `index.html` está na raiz. Os caminhos para recursos e páginas são relativos, funcionando tanto como *project site* quanto como *user site*.

## Estrutura

- `index.html`: página principal
- `assets/styles.css`: estilos
- `assets/main.js`: navegação acessível
- `assets/favicon.svg`: identidade visual
- `projetos/`: estudos de caso individuais
- `docs/README_PERFIL.md`: README preparado para o futuro repositório de perfil `dalmeidait/dalmeidait`

## Transparência

As páginas diferenciam implementação, documentação em andamento e itens planejados. Não são usadas informações confidenciais de empregadores ou clientes.
